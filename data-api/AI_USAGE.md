# AI 사용 기록

AI는 개념 질문과 직접 작성한 코드의 디버깅에만 사용할 수 있습니다. 사용하지 않았다면 아래에 `사용하지 않음`이라고 적습니다. 사용량을 늘릴 필요는 없습니다.

| 허용되는 도움 | 예시 |
|---|---|
| 개념 이해 | HTTP 404와 422의 차이, await의 의미를 다른 예시로 설명해 달라고 질문 |
| 자신의 코드 디버깅 | 직접 작성한 짧은 함수와 오류를 보여 주고 원인과 확인 방법을 질문 |

과제 전체 풀이, TODO의 완성 코드, 참고 답안을 요청하지 않습니다. 디버깅 답변도 이해한 원인과 수정 내용을 자신의 말로 기록하고 다시 실행합니다. API 키, `.env`와 인증 헤더를 질문에 포함하지 않습니다.

## 사용 여부

- 사용 여부: 사용함
- 사용한 도구: Codex 대화형 AI

## 도움 기록

도움을 받은 건마다 표의 행을 추가합니다. 대화 전문보다 질문과 직접 확인한 결과를 구체적으로 적습니다.

| 단계/함수 | 직접 시도한 내용과 문제 | 질문 요약 | 받은 설명 | 내가 수정하거나 확인한 내용 | 재실행 결과 |
|---|---|---|---|---|---|
| `collect_releases` | 수집·저장 TODO를 직접 작성하려고 함 | 페이지·크기, JSON 저장, HTTP 상태 검사, 다음 페이지 확인의 의미를 질문 | `params`, `response.raise_for_status()`, `response.links`, `json.dump`의 역할을 설명받음 | 수집 함수 TODO를 직접 수정함 | `check collect` 실행으로 확인 |
| `normalize_releases` | 원본 자료를 채택·격리·제외하는 조건을 작성함 | boolean 플래그, 제목 대체, 빈 본문, 중복 ID, 문서 값 저장 방법을 질문 | 입력 검증 순서와 `accepted_ids`를 채택 시점에 갱신하는 이유를 설명받음 | 정제 조건과 문서 필드를 직접 수정함 | `check documents` 실행으로 확인 |
| `Document`, `QueryRequest`, `QueryReply` | Pydantic 모델 필드를 작성함 | `Literal`, `Field`, 자료형, 길이와 허용값을 질문 | 모델 필드와 추가 필드 금지, 중복 ID 검증의 목적을 설명받음 | 모델 필드와 검증 TODO를 직접 수정함 | `check document-api` 실행으로 확인 |
| `find_document`, `register_document` | 문서 조회와 중복 등록 조건을 작성함 | 404, 409, 422의 차이와 ID·URL 중복 검사 방법을 질문 | 없는 문서, 중복 등록, 형식 오류의 HTTP 상태 차이를 설명받음 | 조회 및 중복 검사 조건을 직접 수정함 | 문서 API 검사로 확인 |
| `build_prompt`, `call_model_once` | 질문과 선택 문서를 모델에 전달하고 응답을 검증함 | `json.dumps`, `json.loads`, 출처 검사의 의미를 질문 | 모델 입력 JSON, 응답 Pydantic 검증, 선택 문서 ID 비교를 설명받음 | 프롬프트와 응답 검증 코드를 직접 수정함 | `check query` 실행으로 확인 |
| `query_with_retry` | timeout과 5xx 재시도 조건을 작성함 | `attempt`, `await`, `continue`, 429·502·503·504의 차이를 질문 | 첫 시도에서만 재시도하고 공급자 429는 503으로 바꾸는 이유를 설명받음 | 재시도 조건과 상태 코드를 직접 수정함 | `check retry`에서 통과 17, 실패 0 확인 |
| `admit_query` | 요청 제한 구간과 한도 조건을 작성함 | `None`, 시간 차이, `>=`와 `==`의 차이를 질문 | 구간 갱신과 한도 초과 시 대기 시간 계산 방법을 설명받음 | 잘못된 조건을 직접 수정하고 요청 수 증가를 작성함 | `check observe` 실행으로 확인 |
| `request_logging` | 400~406행의 로그 dictionary를 직접 작성함 | 로그를 `키: 값` 형식으로 작성하는지 질문 | `method`, `path`, `status`, `mode`, `elapsed_ms`의 의미를 설명받음 | 다섯 필드만 가진 `fields`를 직접 작성함 | 로그 및 응답 헤더 검사로 확인 |
